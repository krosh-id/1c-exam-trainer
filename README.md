# Практика · 1С:Специалист

Сайт: https://krosh-id.github.io/1c-exam-trainer/

Это готовая статическая сборка React-приложения. Исходники находятся в [source-code.zip](source-code.zip): распакуйте архив для локальной разработки (web/) и инструкции по автоматической публикации (.github/workflows/pages.yml).

Личные конспекты, изображения и прогресс не включены. На сайте откройте «Материалы» и выберите приватный ZIP-пакет, подготовленный локальным экспортёром. На телефоне загрузите тот же ZIP из «Файлов». Прогресс переносится отдельной резервной копией JSON.

Текущая публикация: GitHub Pages → Deploy from a branch → main → /(root). Для последующих обновлений можно загрузить свежую сборку или развернуть исходники из архива и перейти на GitHub Actions согласно web/README.md.

В мобильной сборке строки переносятся. Списки объектов и владельцев показаны полностью. Библиотека заметок, упражнения, проектирование и статистика работают локально в браузере; код 1С не выполняется.
