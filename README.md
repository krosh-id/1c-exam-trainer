# Практика 1С Специалист

Сайт: https://krosh-id.github.io/1c-exam-trainer/

Готовая статическая сборка приложения. [Исходники](source-code.zip) включают web/ и workflow для перехода на автоматическую сборку. Текущая публикация: Pages → Deploy from a branch → main → /(root).

## Схема учёта БУ

В режиме «Спроектируй решение» создавайте показатели, счета и строки субконто, измерений и итогов. На компьютере доступен ввод в таблицу с объединёнными ячейками; на телефоне — карточки и переключение в общий табличный вид. Схема сохраняется автоматически, старые попытки доступны без потери текста. Эталон Word появляется после завершения этапа.

Личные конспекты, заполненные Word-таблицы, изображения и прогресс не опубликованы. Для чтения эталонов загрузите обновлённый приватный materials.zip через «Материалы». Новые Word-таблицы подготовлены для 18 заданий БУ; для №6 отдельный файл не предоставлен. Старые пакеты продолжают работать без новых эталонов. История сохраняется, изменение эталона отмечается новой версией материалов.

## Обновление сайта

Исходный проект: npm ci, затем PAGES_BASE=/1c-exam-trainer/ PAGES_FLAT=1 npm run build (переменные задаются средствами вашей оболочки). Обновите файлы web/dist/ в корне репозитория. Сохраните новую версию source-code.zip. Материалы и резервные копии прогресса в репозиторий не добавляйте.
